Add the avatar to OBS

  1. Sources → + → Browser.
  2. URL: http://localhost:4870/avatar, width 1080, height 1080.
  3. Tick Control audio via OBS so the voice goes into your stream.
  4. Optional: add ?captions=0 to the URL to hide captions, ?question=0 to hide the chat question.
